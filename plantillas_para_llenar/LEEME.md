# Planillas para llenar

Si no tienes estos archivos, descárgalos desde la página web (paso 1, "Planilla para llenar") o cópialos desde aquí, ábrelos con Excel, llénalos y súbelos. Deja la primera fila (los títulos) tal como está.

| Planilla | Cómo llenarla |
|---|---|
| `cotizaciones.csv` | Una cotización por fila. Estado: Aceptada, Rechazada o Pendiente. Fechas como 03/09/2026. Si solo sabes el neto, deja IVA y Total vacíos: se calculan solos |
| `licencias.csv` | Un usuario de un programa por fila (correo, diseño, contabilidad...). Escribe el servicio como aparece en tu cartola (por ejemplo "Canva Pro"). Costo mensual en pesos. Estado: Activa o Cancelada |
| `equipo.csv` | Una persona por fila, con el mismo correo que usa en las licencias. Estado: Activo o Inactivo. Si se fue, anota la fecha de salida |

Al guardar desde Excel, elige el formato "CSV UTF-8" (o "Libro de Excel", que también sirve).
